# 나만의 프롬프트 관리 프로그램

자주 사용하는 AI 프롬프트를 등록하고, 카테고리별/키워드로 찾아보고, 즐겨찾기로 관리할 수 있는 터미널 기반 프로그램입니다.

## 주요 기능

1. **프롬프트 추가** — 제목, 내용, 카테고리를 입력해 새 프롬프트를 등록합니다.
2. **프롬프트 목록** — 등록된 전체 프롬프트를 즐겨찾기 표시와 함께 확인합니다.
3. **카테고리별 조회** — 카테고리를 선택해 해당 카테고리의 프롬프트만 모아 봅니다.
4. **프롬프트 검색** — 제목/내용에 포함된 키워드로 프롬프트를 찾습니다.
5. **프롬프트 상세 보기** — 번호를 선택해 프롬프트의 전체 내용을 확인합니다.
6. **즐겨찾기 관리** — 번호를 선택해 즐겨찾기를 켜거나 끕니다.
7. **즐겨찾기 목록** — 즐겨찾기로 지정한 프롬프트만 모아 봅니다.

## 실행 방법

```bash
python3 main.py
```

실행 후 메뉴에 표시되는 번호(0~7)를 입력해 원하는 기능을 사용합니다.

## 카테고리

텍스트 생성, 이미지 생성, 영상 생성, 페르소나, 자동화, 기타, 직접 입력 중에서 선택할 수 있습니다.

## 개발 환경

- Python 3
